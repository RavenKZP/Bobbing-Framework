#### YOU NEED CMAKE < 3.5 !

#### WINDOWS ENVIRONMENT VARIABLES TO SET

1. **`COMMONLIB_SSE_FOLDER`**: The path to your clone of Commonlib.
2. **`VCPKG_ROOT`**: The path to your clone of [vcpkg](https://github.com/microsoft/vcpkg).
3. (optional) **`SKYRIM_FOLDER`**: path of your Skyrim Special Edition folder.
4. (optional) **`SKYRIM_MODS_FOLDER`**: path of the folder where your mods are.

#### Mod Page

[Bobbing Framework - Nexus](https://www.nexusmods.com/skyrimspecialedition/mods/186081)

Bobbing Framework is an SKSE plugin that brings subtle, immersive motion to Skyrim's static world. 
It animates existing objects with configurable floating motion entirely at runtime, without replacing meshes or modifying plugins.
